# Simmer & Smoke — a cooking game for the make.fun best-cooking-game bounty

[![bounty](https://make.fun/badge/best-cooking-game-20261125-0137.svg)](https://make.fun/bounty/best-cooking-game-20261125-0137)
[![rank](https://make.fun/badge/best-cooking-game-20261125-0137/Kaksyeh/best-cooking-game-20261125-0137/rank.svg)](https://make.fun/bounty/best-cooking-game-20261125-0137/leaderboard)
[![reward](https://make.fun/badge/best-cooking-game-20261125-0137/Kaksyeh/best-cooking-game-20261125-0137/reward.svg)](https://make.fun/bounty/best-cooking-game-20261125-0137)

You run a smokehouse bistro for one 180-second dinner shift. Orders appear on the board with per-order timers: walk the kitchen, pick up ingredients, chop them at the board, cook on the two-burner stove (leave food too long and it burns), assemble dishes, and serve them at the pass before the timer runs out. Serve fast for tips. Three recipes from six ingredients — Tomato Soup, Pasta al Forno, Garden Salad — plus one rush bell per shift that adds 10 seconds to every open order. Reach 300 points to win; fail 3 orders and the shift ends early.

## Run it

Serve `game/` with any static server and open `game/index.html` in desktop Chrome. No network, no build step. WASD/arrows to walk, E to pick up / place / serve, hold E to chop, Space for the rush bell, P to pause, M to mute.
